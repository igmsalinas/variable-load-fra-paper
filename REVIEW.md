# Joint review of the papers, code and datasets

The audit used the [experiment code at 9e13ccd](https://github.com/igmsalinas/fault-converters-code/tree/9e13ccdd263346e2eadd15102fe096393a64d38a) and [data at 4950ecf](https://github.com/igmsalinas/fault-converters-data/tree/4950ecf604fab8b63395201b2d4a28af88fae8e8). The active variable-load manuscript is in this repository. The code repository contains the fixed-load anomaly-detection paper and the Jetson Nano deployment paper.

## Verified results

| Scope | Evidence |
| --- | --- |
| Variable-load data | The manifest contains 800 unique sweeps with 101 finite magnitude and phase measurements on a shared logarithmic 100 Hz–50 kHz grid. Regenerating the sampling plan from seed 102 recovered the manifest. The 500 healthy and 300 faulty sweeps split into 300 healthy training sweeps, 100 healthy and 90 faulty fit-validation sweeps, and 100 healthy and 210 faulty test sweeps. All six saved split arrays matched an independent reconstruction. The code and data repositories contain the same sweeps, manifest and metadata after line-ending normalization. |
| Converter model | The Table I bounds now follow the sampled parameter multipliers. The central 95% of the healthy peak response spans 8.47 dB. Recomputing the complex relative response error gave a median of 0.09525% at the true simulated loads and 14.874% when evaluating the model at 4 Ω. Those calculations compare plant responses. A matched-load fault-augmentation error analysis would require paired healthy and faulty sweeps. |
| Variable-load detector | The saved configurations use one single-component negative per anchor, positive jitter and scaling, matched initial weights, and healthy validation for checkpoint selection and threshold calibration. The final ten-seed table gives F1 0.94166 ± 0.01284 and average precision 0.91257 ± 0.03077 at an assumed 5% prevalence. Test false positives ranged from 0 to 6 out of 100 healthy sweeps. Replaying all ten archived checkpoints on CPU with the raw sweeps, frozen split and saved preprocessor yielded F1 0.94254 ± 0.01238 and adjusted AP 0.91417 ± 0.03015. The paper reports the original run. Ranking metrics calculated from the intermediate score cache were also close to the final table, with per-seed absolute differences of at most 0.00072 in ROC AUC and 0.00112 in adjusted AP across the three methods stored in that cache. |
| Fixed-load detector | All eleven archived per-state prediction tables share the same ordered 1,268 physical states and labels (520 healthy, 748 faulty). The five-fault comparison excludes 82 low-side-switch-only cases, leaving 520 healthy and 666 faulty. The companion paper's five benchmark rows and three paired ablation deltas match saved predictions. Its selected scorer is model-specific and uses labeled fit-validation data to select the scorer and threshold. |
| Jetson Nano | Archived consistency reports support 37 accepted and eight fidelity-rejected FP32/FP16 configurations. The ten executable CPU INT8 variants changed 49.8%–54.6% of decisions relative to FP32. The revised paper separates neural latency from whole-detector runtime and converts watt-seconds per inference to millijoules. The reports concern numerical agreement on the archived test set and the measured hardware configuration. |
| Source checks | Both source publication audits passed. The Python suite passed all 175 tests in the available environment. These checks cover the source and archived outputs. |

## Before journal submission

1. Recover the exact raw fixed-load Dataset 01 sweeps, simulator inputs and sweep identities. The legacy ZIP contains 161,051 grid sweeps. Its inventory does not establish the 4,723-state cohort used by the fixed-load papers. Keep the legacy archive and corrected campaign documented separately.
2. Record the original evaluation environment and rerun all secondary analyses with the frozen splits, preprocessors and weights. The primary variable-load CPU replay is already checked. Exact training reproducibility requires the corresponding historical source revisions and simulator configuration.
3. Measure the nominal-load augmentation error on paired healthy and faulty samples at controlled loads. The current data support simulation results on one split. Hardware FRA, independent splits and changed operating conditions require separate validation. A new Jetson campaign would be required to measure end-to-end latency and power for the variable-load model.
