# Data and code availability

- [Code snapshot](https://github.com/igmsalinas/fault-converters-code/tree/9e13ccdd263346e2eadd15102fe096393a64d38a) contains the experiment code and derived publication results.
- [Data snapshot](https://github.com/igmsalinas/fault-converters-data/tree/4950ecf604fab8b63395201b2d4a28af88fae8e8) contains the variable-load sweeps, manifests, split and stored experiments. Large files use Git LFS.
- Access to both repositories requires GitHub permissions. The exact raw cohort used for the manuscript’s fixed-load comparison remains to be archived. The saved evaluation records for that comparison are available in the corrected campaign.

## Release wording

Once a tagged release has been verified from a clean checkout and the repository's access policy has been decided, use this statement with the actual release links and access terms.

> The experiment code and summary results are available at [code release URL]. The variable-load sweeps, manifest, split and archived experiment artifacts are available at [data release URL]. Large artifacts use Git Large File Storage (Git LFS). [State any access restrictions and the availability of the fixed-load raw cohort.]

Verify download permissions, LFS objects, checksums, archive contents and the readme commands before citing the release. Cite a DOI if the materials are deposited in a DOI-issuing archive.
