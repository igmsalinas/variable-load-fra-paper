# Data and code availability

- [Code repository](https://github.com/igmsalinas/fault-converters-code) contains the experiment code and derived publication results.
- [Data repository](https://github.com/igmsalinas/fault-converters-data) contains the variable-load sweeps, manifests, split and stored experiments. Large files use Git LFS.
- Both repositories are public on GitHub. The data repository also contains the saved fixed-load evaluation records.

## Release wording

For a tagged release, verify the release from a clean checkout and cite the exact release links.

> The experiment code and summary results are available at [code release URL]. The variable-load sweeps, manifest, split and archived experiment artifacts are available at [data release URL]. Large artifacts use Git Large File Storage (Git LFS).

Verify download permissions, LFS objects, checksums, archive contents and the readme commands before citing the release. Cite a DOI if the materials are deposited in a DOI-issuing archive.
